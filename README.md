**Nightshade — The Ember Vault** is an original top-down 2D stealth game built for make.fun's "Make the best stealth game" bounty. You are a lone infiltrator slipping through a guarded vault: sneak past patrolling wardens and their vision cones, hide in shadow pools behind crates, steal all three ember cores, and reach the exit unseen.

Guards patrol waypoints, grow suspicious when they glimpse you, give chase when they are sure, and search your last-known position when you break line of sight. Running is fast but loud — your footsteps carry a visible noise ring that wardens can hear. Crouch-sneaking is slow and quiet, and shadows slow detection to a crawl. Three hand-built levels escalate from two patrols to four, with a live detection meter, alert sting, footstep audio, and win/lose/restart flow — all sound synthesised live with WebAudio, no audio files, no network requests.

## Run it

```sh
python3 -m http.server --directory game 8080
# then open http://localhost:8080 in desktop Chrome
```

Controls: WASD / arrow keys move · SHIFT sneak · M mute · R restart · ENTER start / advance.
